## Boundary

Asset | Controller
--- | ---
Command and cancellation | Caller
Executable and descendants | Local
Process ownership | Operating system
Input, output and time bounds | Proctree

## Failure classes
- Shell interpretation
- Execution before ownership
- Unbounded input or output
- Surviving descendants after controller exit
- Return before cleanup
- Hidden cleanup failure
- Unauthorised watchdog signalling
- Weaker fallback on unsupported platforms
